Своя ОС.
Своё ядро.

KotOS загружается через Multiboot, рисует консоль на framebuffer, выполняет программы в ring 3 и показывает окна. Без Linux внутри.

Так это выглядит

Реальные скриншоты из QEMU: графический режим с окном терминала и консоль с кириллицей.

Что внутри

Маленькое ядро, но настоящие механизмы: загрузка, память, прерывания, пользовательский режим и графика.

01

Своё ядро

Multiboot, 32-битный x86, сборка без libc: gcc -m32 -ffreestanding и свой линкер-скрипт.

02

Терминал и RAMFS

Команды KotOS и файлы в памяти: до 64 узлов, файлы до 512 байт, перенаправление > и >>.

03

Ring 3 и syscalls

Отдельная программа на 0x400000, переход в пользовательский режим и вызовы через int 0x80.

04

Кириллица

Собственная консоль в framebuffer и шрифт CP866: русский текст виден и в шелле, и в GUI.

05

Окна и мышь

Панель с часами, перетаскиваемые окна, курсор PS/2. Интерфейс рисуется напрямую в видеопамять.

06

Запуск в QEMU

Одна команда make run — и система стартует. Без установки, разделов и загрузчика на диске.

Команды

Имена в стиле KotOS; привычные Linux-команды работают как алиасы.

# файлы look go where newdir newfile show say del copy move dropdir rename append # текст top bottom count findtext sort rev hex seq find tree # система clock uptime vars host me mem sysinfo who which stat du history sleep user exit
  • RAMFS живёт в памяти и очищается при перезагрузке.
  • say текст > файл и say текст >> файл — запись и дописывание.
  • user запускает программу в ring 3 через syscall'ы.
  • install gui открывает графический режим; Esc — назад в терминал.

Собрать и запустить

Нужны gcc, binutils и QEMU. Сборка занимает секунды: ядро маленькое.

# клонировать и собрать git clone https://github.com/damiry947/KotOS.git cd KotOS make make run # в QEMU: kotos> install gui # альтернатива вручную: qemu-system-x86_64 -kernel kernel/kernel.elf -m 64

  1. Зависимости

    gcc, binutils, qemu-system-x86. Для GUI — стандартный VGA QEMU.

  2. Сборка

    make собирает ядро и пользовательскую программу в kernel.elf.

  3. Запуск

    make run открывает QEMU. Введите install gui для графики.

Дальше

Честно о статусе: это работающая система, но ещё не замена Linux.

  • Планировщик и процессыСейчас один пользовательский процесс; дальше — вытеснение и несколько задач.
  • ДискиRAMFS только в памяти; нужны драйверы и ФС для установки на SSD.
  • СетьСетевого стека пока нет — только локальные команды.
  • GUIДва окна, простой z-порядок; в планах — resize, меню и больше приложений.
